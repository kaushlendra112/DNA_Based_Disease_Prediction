🧬 DNA-Based Disease Prediction
📌 Description

This project predicts genetic disease risk using DNA variation data such as SNPs (Single Nucleotide Polymorphisms). It calculates the Polygenic Risk Score (PRS) and classifies disease risk levels (Low, Medium, High) using machine learning models like Random Forest, Gradient Boosting, SVM, and Logistic Regression.

The system integrates GWAS dataset and patient genotype data to support early disease-risk analysis for research and precision medicine applications.
